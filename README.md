# dsh-sidebar-chat

在 DeepSeek Harness 里把**任意一个会话**单独拎出来，放进一个悬浮在界面上的小窗里读、往里面说话——不用切走当前正在跑的会话。

收起时是右下角一颗球，点开是一张浮窗卡片；内容走的是 DSH 自己的会话数据，不另起一份状态。

---

## 这是什么

一边跑着 A，突然想起 B 也得改一句。以前只能切过去、改完、再切回来，A 的滚动位置和节奏全断了。

这个插件给你第二条路：在侧栏 B 上点「⋯ → **弹窗打开**」，B 就在右下角浮着，可以读、可以接着回复，A 该跑还跑。

球和当前主对话是两个视图，**同一份会话**：窗里发一句，主面板那边立刻能看到；主面板在跑，窗里也能看到工具在动。

## 功能

**两种形态**

- 悬浮球（52px）：可拖动，位置记住；会话在跑时外圈有转动的弧；开了多个会话时右上角显示数量。
- 浮窗卡片（默认 420×600）：标题栏可拖、右下角可拉伸，尺寸位置都记住；球与窗之间一键切换。
- 点球展开，点标题栏的 `⌄` 收回，点 `✕` 清空会话并收回；**右键球**可以隐藏，下次从会话菜单再打开。

**对话渲染**

- 助手正文按 DSH 官方 Chat 的 markdown 样式表渲染（标题、列表、表格、引用、代码块、任务列表、链接）。
- 代码块带语言标签、复制按钮，以及命令 / 关键字 / 字符串 / 数字 / 注释五类语法高亮。
- 工具调用用官方那套语义文案（「执行了命令并已读取文件」），按**时间顺序**穿插在正文里；每条可展开看命令行与输出。
- 每个回合顶部一行摘要：「执行了命令，已读取文件 · 用时 2分4秒」。
- 任务清单渲染成卡片：完成 / 进行中 / 待处理三态，**只有会话真的在跑时才转动**。
- 回合失败会显示「处理失败 / 本轮运行失败 {原因}」，不会像以前那样整轮消失。
- 用户消息里的图片显示缩略图，点开全屏；长回答 hover 出复制。

**输入**

- Enter 发送 / Shift+Enter 换行，运行中可停止。
- 模型切换：读的是官方 per-session 模型目录，和主面板双向同步。
- 图片附件：点 `+` 或直接粘贴，走 `PromptContentPart` 的 image part。
- `@` 补全：从当前对话里已经出现过的文件路径中筛选插入。

## 安装

插件是一个本地的 DSH bundle（无构建步骤、无运行时依赖）：

```sh
# 从本地目录安装（path 形式）
dsh plugin --profile desktop add -w /path/to/dsh-sidebar-chat
```

装完**重启 DSH**。插件市场里会显示为「侧栏会话」。

卸载：

```sh
dsh plugin --profile desktop remove dsh-sidebar-chat
```

装的是软链：改这里的文件不会立刻生效，重装一次或重启 DSH 才是新代码。

## 使用

1. 随便打开一个会话，正常干活。
2. 在侧栏另一个会话上点「⋯」→「弹窗打开」。
3. 右下角出现浮窗，显示的就是那个会话；拖标题栏可以挪到顺手的位置。
4. 要回到完整界面（左右栏、轨迹、文件树都在），点标题栏的 `↗`。

## 实现要点

插件是纯 Client 半侧（`index.js` 的 `apply()` 是空的），只往两个插槽里注册：

| 插槽 | 内容 |
|---|---|
| `sidebar.workspaces.session.menu.item` | 会话「⋯」菜单里的一行 |
| `shell.overlay` | 悬浮球 / 浮窗 |

会话数据走 `ctx.sessions.retain(sessionId, { source: 'gateway' })`：`binding.eventSource` 读历史与实时增量，`binding.session.prompt()` 发消息、`cancel()` 停止、`loadOlder()` 翻页。**和主面板共用同一个会话世代**，所以两边不会各说各话。

渲染上做了几件"抄官方"的事：

- markdown 样式表从 DSH 前端的 `.md` 规则整段提取（78 条），只改类名前缀；
- 工具摘要的拼接规则（`{first}并{second}`、「，」、「等」）和文案表照抄官方 `chat` locale；
- 三态任务圆环用 SVG 画（CSS border 拼不出"完整的圆 + 局部转动"）。

## 已知限制

- 出不了 DSH 的窗口。它是页面内的浮层，不是独立桌面窗口——要那种形态得另起进程。
- 审批卡、提问卡、workflow 卡不渲染，会归到「已调用工具」；需要处理时点 `↗` 回主面板。
- 消息渲染上限 400 条（合并后的回合块），超出的部分靠「加载更早」。
- `@` 只补全**当前对话里出现过**的路径，不是全工作区文件搜索。
- 语法高亮是 token 级，不是 parser；复杂嵌套可能着色不准，但不会出错。

## 开发

单文件、无构建：改 `client.js` → 重装 bundle → 重启 DSH。

```sh
# 校验
node --check client.js
```

主要常量在文件顶部：`BALL_SIZE`、`PANEL_WIDTH`、`PANEL_HEIGHT`、`MAX_MESSAGES`、`MAX_IMAGES`、`CODE_COLLAPSE_LINES`。
配色全部走主题 token（`--dsw-alias-*`），不写死颜色（语法高亮除外）。
